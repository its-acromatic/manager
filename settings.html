Spotlight Guide

Quick Capture: Press Cmd+K or Ctrl+K to open Spotlight from anywhere.

Set the Type

Start with task, event, exam, reminder, focus, or note to choose the type directly. The first word is removed from the saved title. Without a type word, Spotlight infers one and defaults to a task.

Dates and Times

  • Dates: today, tomorrow, tonight, monday, next monday, this saturday, 25 dec, 25 december, june 12, 12/06/2026, after 3 days, next week.
  • Clock times: 5pm, 5:30pm, 8:30 am, 17:30, noon, midnight.
  • Time of day: morning (9 AM), afternoon (2 PM), evening (6 PM), night/tonight (9 PM).
  • A weekday without a modifier means its nearest occurrence. Numeric dates use DD/MM/YYYY or DD-MM-YYYY.
  • A bare hour such as 5 is ambiguous, so it is left unscheduled; add am, pm, or at 17:00.

Priority and Tags

Add urgent, high, medium, or low to set priority. Add tags with #tag.

Examples

  • task finish physics homework tomorrow 5pm urgent → Task, Physics Homework, tomorrow at 5 PM, urgent.
  • event annual function 25 december → Event on December 25.
  • exam chemistry monday 8am → Chemistry exam on the nearest Monday at 8 AM.
  • reminder call sir tonight → Reminder for tonight at 9 PM.
  • focus deep work 9pm → Focus capture scheduled for 9 PM.
  • meeting with sir friday 2:30pm #college → Event with a college tag, Friday at 2:30 PM.

Check the live preview before saving. Spotlight shows a subtle note when a time is unclear; correct it in the input if needed.
